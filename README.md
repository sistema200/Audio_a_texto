# Audio_a_texto
Convierta audio .wav a texto plano sin costo alguno totalmente gratis 

## Instalación

Clona este repositorio:

```bash
git clone https://github.com/sistema200/Audio_a_texto.git
```
Entra a la carpeta 
```bash
cd Audio_a_texto
```
Ejecuta el instalador
```bash
bash ./install.sh
```
Ejecuta el Programa
```bash
./start.sh
```
